COURSE OVERVIEW

Advanced Paradigms
for Robust Software

This course examines advanced paradigms for designing and implementing robust software systems in C++. Building on foundational knowledge, it delves into sophisticated programming concepts and industry-standard practices.

Advanced OOP & Design Patterns
Generic Programming & STL (Containers, Algorithms)
Modern C++ Standards: move semantics, lambdas, smart pointers
Concurrent programming & Multithreading models
GUI Application Development (Qt / modern C++ GUI)

Goals & Expectations

  • Master advanced C++ features (classes, move semantics, lambdas, etc).
  • Design efficient apps using STL containers and algorithms.
  • Write safe, exception‑safe, resource‑managed code (RAII, smart pointers).
  • Apply OOP principles and design patterns (State, Observer, Singleton).
  • Design GUI & use concurrency / multithreading for parallel programming.
  • Integrate unit tests using Test‑Driven Development principles.
